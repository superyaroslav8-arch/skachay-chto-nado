# Скачай, что надо!

Современный адаптивный каталог приложений и игр для **iPhone**, **iPad** и **Android**.

## Возможности

- 🔍 Быстрый поиск по названию, разработчику и категориям
- 📱 Автоопределение устройства пользователя
- 🗂 Категории: Игры, Мессенджеры, Соцсети, ИИ, Музыка, Видео и др.
- 📄 Страницы приложений с реальными ссылками на App Store / Google Play / веб-версии
- ⭐ Избранное (локальное хранилище)
- 🕐 История просмотров
- 🌙 Тёмная / светлая тема
- 📲 Полностью адаптивный дизайн

## Важно

- Все ссылки ведут **только** на официальные источники (App Store, Google Play, сайты разработчиков).
- Нет фейковых кнопок скачивания и выдуманных приложений.
- Для платных приложений честно указывается, что бесплатная легальная установка недоступна.
- Если прямая установка на устройство невозможна — предлагается веб-версия (если существует).

## Структура

```
├── index.html          # Главная страница (SPA)
├── css/styles.css      # Стили
├── js/app.js           # Логика
├── data/apps.json      # Каталог приложений (легко расширять)
└── README.md
```

## Как добавить приложение

Отредактируйте `data/apps.json`. Добавьте объект по образцу существующих записей. HTML менять не нужно.

## Запуск

Откройте `index.html` в браузере или разместите на любом статическом хостинге (GitHub Pages, Netlify, Vercel и т.д.).

Для GitHub Pages:
1. Settings → Pages → Source: Deploy from branch `main`
2. Сайт будет доступен по адресу `https://<username>.github.io/skachay-chto-nado/`

## Технологии

- Чистый HTML + CSS + JavaScript (без тяжёлых фреймворков)
- localStorage для избранного, истории и темы
- Асинхронная загрузка каталога из JSON
- Lazy loading иконок

## Лицензия

Проект создан для удобства пользователей. Данные о приложениях и ссылки — публичные официальные источники.
